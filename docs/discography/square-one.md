# SQUARE ONE

《SQUARE ONE》是 BLACKPINK 的出道作品，也是第一張單曲專輯，於 2016 年 8 月 8 日發行。專輯收錄〈WHISTLE〉與〈BOOMBAYAH〉兩首主打歌，四位成員從這張作品開始了團體活動。
